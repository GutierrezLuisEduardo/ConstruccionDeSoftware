Preguntas

  1. ¿Cuál es la diferencia entre Internet y la World Wide Web?
    Internet es la red global de computadoras interconectadas. La World Wide Web es un servicio que funciona sobre Internet y permite acceder a páginas web.
  2. ¿Cuáles son las partes de un URL?
    Las partes de un URL son el protocolo (http:// o https://), el dominio/host (www.ejemplo.com), puerto (:24, p.ej), ruta (/pagina), los parámetros de consulta (?) y el fragmento (#).
  3. ¿Cuál es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH, DELETE?
    GET: obtiene recursos, HEAD: obtiene solo encabezados, POST: envía datos para crear, PUT: reemplaza o crea un recurso, PATCH: actualiza parcialmente un recurso, DELETE: elimina un recurso.
  4. ¿Qué método HTTP se debe utilizar al enviar un formulario HTML, por ejemplo cuando ingresas tu usuario y contraseña en algún sitio? ¿Por qué?
    Se debe utilizar el método POST porque envía los datos en el cuerpo de la solicitud y no los muestra en la URL.
  5. ¿Qué método HTTP se utiliza cuando a través de un navegador web se accede a una página a través de un URL?
    El método HTTP que se utiliza al acceder a una página a través de un URL en el navegador es GET.
  6. Un servidor web devuelve una respuesta HTTP con código 200. ¿Qué significa esto? ¿Ocurrió algún error?
    El código 200 significa OK, y que la solicitud fue exitosa.
  7. ¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intentó acceder al sitio y se encontró con un error 404? ¿Por qué?
    Solamente si hubo una redirección que no ha sido actualizada, pero si el sitio nunca existió o fue eliminado, no debería de ser corregida.
  8. ¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intentó acceder al sitio y se encontró con un error 500? ¿Por qué?
    Sí, es responsabilidad del desarrollador corregir un error 500 porque indica un problema interno del servidor.
  9. ¿Qué significa que un atributo HTML5 esté depreciado o desaprobado (deprecated)? Menciona algunos elementos de HTML 4 que en HTML5 estén desaprobados.
    Un atributo o elemento depreciado significa que ya no se recomienda su uso y tiende a ser removido en el futuro. Algunos elementos de HTML 4 desaprobados en HTML5 son: font, marquee, frame y frameset.
  10. ¿Qué componentes de estructura y estilo tiene una tabla?
    Una tabla tiene: table (contenedor), thead (encabezado), tbody (cuerpo), tfoot (pie), tr (filas), th (celdas de encabezado) y td (celdas de datos).
  11. ¿Cuáles son los principales controles de una forma HTML5?
    Los principales controles de un formulario HTML5 son: input (text, password, email, number, date, etc.), textarea, select, button, checkbox, radio, fieldset y legend.
  12. Sobre el ciclo de vida y desarrollo de los sistemas de información: ¿Cuál es el ciclo de vida de los sistemas de información? ¿Cuál es el ciclo de desarrollo de sistemas de información?
    El ciclo de vida de los sistemas de información incluye: planeación, análisis, diseño, implementación, mantenimiento y retiro. El ciclo de desarrollo de sistemas es: planificación, análisis de requisitos, diseño, desarrollo, pruebas, implementación y mantenimiento.
