# El archivo package.json del proyecto npm
Es un archivo de configuración del proyecto de npm que contiene información y contexto del proyecto, tales como el nombre, versión, descripción, palabras clave, tipo de licencia, autor, script principal, versiones y nombre de dependencias.

Particularmente en el apartado de scripts, puse dos scripts: 
- "dev", reinicia al servidor con c/cambio en el archivo
- "start", arranca el servidor
